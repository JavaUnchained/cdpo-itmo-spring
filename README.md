## Домашняя работа 7
Реализовать функционал отправки статистической информации раз в сутки:
1. Приложение раз в сутки отправляет http запросы в сервис DWH (хранилище статистики). 
   В запросе передается информация о предоставленных услугах. В ответ возвращается список с id успешно обработанных записей записей.
2. Если запрос не был передан, в ответ вернулся не пустой список, данные необходимо отправить повторно
2. Для отправки запросов использовать feignclient для профиля feign и restclient для профиля rest. 
   У реализаций (сервисов) должна быть единая абстракция - интерфейс. Внедрение зависимостей осуществлять через интерфейс
3. Самостоятельно изучить и реализовать в feign client механизм повторных попыток  - Retryer и механизм обработки ошибок.
4. Для проверки сервис DWH (хранилище статистики) можно реализовать только с контроллером, который принимает запросы и формирует случайный список с идентификаторами

Механизм работы: раз в сутки тех.сервис отправляет post запрос в сервис DWH, передает информацию о всех бронях со статусом - предоставлено. 
Кроме этого необходимо передавать перечень услуг, стоимость с учетом скидки и идентификатор пользователя.
