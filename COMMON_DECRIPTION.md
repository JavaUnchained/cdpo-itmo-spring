Авто сервис:
Итоговый проект будет состоять из следующего функционала. По нему будут формироваться ДЗ

Возможности пользователя:
1. просматривать список предоставляемых услуг. По каждой услуге обязательно отображать примерное время
2. создавать/изменять свои брони (одна бронь включает в себя несколько услуг)
3. просматривать список своих броней услуг (сортировка по дате, фильтр по типу: завершенные, отмененные, новые)
4. создавать/изменять свой аккаунт. Данные которые были собраны по пользователю не должны удаляться из системы (для статистики)
5. восстанавливать пароль по почте

Возможности администратора:
1. добавлять/изменять услуги
2. получить бронь(и) по дате-времени записи
3. редактировать бронь любого пользователя
4. регулирование минимального и максимального размера скидки, предоставляемой оператором
5. получить информацию выручке за определенный период времени (в виде дата - выручка)
6. добавлять/редактировать профиль оператора

Возможности оператора:
1. получить бронь(и) по дате-времени записи
2. отменить бронь, созданную пользователем
2. назначать/убирать скидку для всю бронь
3. редактировать бронь
4. регулирование минимального и максимального размера скидки, предоставляемой оператором
5. получить выручку за определенный период времени (в виде дата - выручка)
6. добавлять/редактировать профиль оператора



Требования к системе:
1. журналирование действия администраторов и операторов в БД
2. автоматическая отмена брони, есть клиент не приехал за 15 минут до начала (нет отметки в таблице 'Бронь')
3. бронь должна подтверждаться в течении 15 минут, по ссылке, в противном случае бронь должна автоматически аннулироваться. Функционал отправки письма на почту следует имитировать выводом в консоль (то есть не надо прям реально писать интеграцию с почтовиком, просто выводите в консоль ссылку вида http://localhost:8080/….)
4. автоматически определять возможность записи на определенный перечень услуг, исходя из наличия свободных мест
